# OpenCTD 3D Printed Models
The  primary 3D printer files for assembling an OpenCTD Rev8.

## Baseplates (print with 100% infill to avoid voids where water may enter)
- [OpenCTD_Rev8_Baseplate_CPS](https://github.com/OceanographyforEveryone/OpenCTD/blob/main/Hardware/3DPrints/OpenCTD_Rev8_Baseplate_CPS.3mf): Baseplate for the Rev8 OpenCTD using an Oceanography for Everyone Custom Pressure Sensor Breakout Board.
- [OpenCTD_Rev8_Baseplate_SF](https://github.com/OceanographyforEveryone/OpenCTD/blob/main/Hardware/3DPrints/OpenCTD_Rev8_Baseplate_SF.3mf): Baseplate for the Rev8 OpenCTD using a Spark Fun Pressure Sensor Breakout Board.
- [OpenCTD_Rev8_Baseplate_IMU](https://github.com/OceanographyforEveryone/OpenCTD/blob/main/Hardware/3DPrints/OpenCTD_Rev8_Baseplate_IMU.3mf): Baseplate for the Rev8 OpenCTD using an OpenROV IMU.

## PowerSquid Chassis (print with 50% infill to maximize strength and print speed)
- [OpenCTD_Rev8_Chassis_Top](https://github.com/OceanographyforEveryone/OpenCTD/blob/main/Hardware/3DPrints/OpenCTD_Rev8_Chassis_Top.3mf): The top section of the PowerSquid electronics chassis.
- [OpenCTD_Rev8_Chassis_Bottom](https://github.com/OceanographyforEveryone/OpenCTD/blob/main/Hardware/3DPrints/OpenCTD_Rev8_Chassis_Bottom.3mf): The bottom section of the PowerSquid electronics chassis.
- [OpenCTD_Rev8_Chassis_Cap](https://github.com/OceanographyforEveryone/OpenCTD/blob/main/Hardware/3DPrints/OpenCTD_Rev8_Chassis_Cap.3mf): The end cap for the PowerSquid electronics chassis. 

## Router Jigs (print with 100% infill for maximum durability)
- [Router_Jig_for_Housing_1](https://github.com/OceanographyforEveryone/OpenCTD/blob/main/Hardware/3DPrints/Router_Jig_for_Housing_1.3mf): Router jig to cut the initial notch in the PVC housing.
- [Router_Jig_for_Housing_2](https://github.com/OceanographyforEveryone/OpenCTD/blob/main/Hardware/3DPrints/Router_Jig_for_Housing_2.3mf): Router jig to cut the second and third notch in the PVC housing.

## Accessories (print with 50% infill to maximize strength and print speed)
- [Cap_Wrench](https://github.com/OceanographyforEveryone/OpenCTD/blob/main/Hardware/3DPrints/Cap_Wrench.3mf): Wrench for tightening and loosening the plumbers test cap on the OpenCTD.

*3D printer shapefiles updated 6/17/2026 for compatibility with the Rev8 control board.*

# OpenCTD PCB

The OpenCTD main board is designed using [KiCad](https://www.kicad.org/).

The current [OpenCTD]() uses the [OpenCTD Rev8 control board](). Previous generation control boards are archived in [Retired](https://github.com/OceanographyforEveryone/OpenCTD/tree/main/Retired). 

The Oceanography for Everyone Custom Pressure Sensor breakout board ([Ofe_CPS](https://github.com/OceanographyforEveryone/OpenCTD/blob/main/Hardware/PCB/OfE_CPS.zip)) allows you to build an inexpensive version of the Sparkfun Breakout Board, but requires advanced soldering techniques.
